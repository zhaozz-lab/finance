# Econ251｜Lecture 4 笔记（Geanakoplos）
> 来源：Chapter1~Chapter4 课程原文，适配Obsidian，直接复制可用
> 模型：Fisher两期金融一般均衡，两代理人 + 两支股息股票

## 一、基础定义
- $X_1$：时期1（今天）的苹果
- $X_2$：时期2（明年）的苹果
> 要点：物理上是同一种苹果，但**时间不同=不同商品**，Fisher把时间维度转化为商品，直接套用一般均衡框架

### 代理人效用（课上给定）
Agent A（相对不耐受，折现未来消费）
$$U_A=\ln X_{A1}+\frac12\ln X_{A2}$$

Agent B（更有耐心，不对未来效用打折）
$$U_B=\ln X_{B1}+\ln X_{B2}$$

### 禀赋 $E_i=(E_{i1},E_{i2})$
- $E_{i1}$：代理人i在时期1自带的苹果禀赋
- $E_{i2}$：代理人i在时期2自带苹果禀赋（可理解为未来劳动收入对应的实物）

### 股票、股息D
- 股票$\alpha$：$D_{\alpha2}=1$，时期2派发股息1苹果
- 股票$\beta$：$D_{\beta2}=2$，时期2派发股息2苹果
> $D_{s2}$ = 股票s在时期2的预期股息；模型假设完美预见，股息确定

### 初始股权禀赋 $\bar\theta$（课上给定）
- $\bar\theta_{A\alpha}=1,\ \bar\theta_{B\alpha}=0$：A一开始拥有全部$\alpha$股票
- $\bar\theta_{A\beta}=\tfrac12,\ \bar\theta_{B\beta}=\tfrac12$：A、B一开始各持有一半$\beta$股票
- $\theta_{i\alpha},\theta_{i\beta}$：代理人i期末持有的$\alpha、\beta$股份数量
- $\theta_{i\alpha}<0$ = **卖空 short sale**：卖出并不拥有的股票，当期获得资金，未来必须交割股息

### 价格符号
- $q_1$：时期1当期苹果现价
- $q_2$：时期2当期苹果现价
- $p_\alpha$：时期1 $\alpha$股票价格
- $p_\beta$：时期1 $\beta$股票价格
> 时期2股票价格=0：两期模型，期末无后续股息，股票无价值

## 二、两期预算约束（金融均衡核心）
> Agent i，分时期1、时期2两个预算等式
**时期1（今天）预算**
$$q_1 X_{i1}+p_\alpha \theta_{i\alpha}+p_\beta \theta_{i\beta}
= q_1 E_{i1}+p_\alpha \bar\theta_{i\alpha}+p_\beta \bar\theta_{i\beta}$$
左边：今天总支出 = 买当期苹果 + 买入$\alpha、\beta$股票
右边：今天总财富 = 当期苹果禀赋价值 + 卖出初始持股的收入

**时期2（明年）预算**
$$q_2 X_{i2} = q_2 E_{i2}+q_2\cdot \theta_{i\alpha} D_{\alpha2}+q_2\cdot \theta_{i\beta} D_{\beta2}$$
左边：明年购买苹果的支出
右边：明年收入 = 时期2自带苹果禀赋价值 + 持股带来的股息价值

> 假设：无违约、无抵押，承诺一定兑现；时期2不再交易股票，只有股息收入

## 三、市场出清条件（均衡必须全部满足）
1. 时期1商品市场
$$X_{A1}+X_{B1}=E_{A1}+E_{B1}$$
2. 时期2商品市场（总消费=禀赋苹果+全部股票产出股息）
$$X_{A2}+X_{B2}=E_{A2}+E_{B2}+\bar\theta_\alpha D_{\alpha2}+\bar\theta_\beta D_{\beta2}$$
其中 $\bar\theta_\alpha=\bar\theta_{A\alpha}+\bar\theta_{B\alpha},\ \bar\theta_\beta=\bar\theta_{A\beta}+\bar\theta_{B\beta}$

3. 股票市场出清（股份总量固定，仅转手）
$$\theta_{A\alpha}+\theta_{B\alpha}=\bar\theta_{A\alpha}+\bar\theta_{B\alpha}$$
$$\theta_{A\beta}+\theta_{B\beta}=\bar\theta_{A\beta}+\bar\theta_{B\beta}$$

## 四、套利 Arbitrage 核心公式
资产仅股息规模不同时，均衡价格与股息成正比：
$$\frac{p_\alpha}{D_{\alpha2}}=\frac{p_\beta}{D_{\beta2}}$$
代入课上股息 $D_{\alpha2}=1,\ D_{\beta2}=2$：
$$p_\alpha=\frac12 p_\beta$$
> 含义：相同时间、相同风险，仅股息规模不一样的资产，单位股息价格相等；否则存在无风险套利机会

## 五、通胀、名义利率定义（课上版本）
1. 通胀因子（苹果跨期价格变化）
$$\text{通胀因子} = \frac{q_2}{q_1}$$
- $\dfrac{q_2}{q_1}>1$：明年苹果更贵 → 通胀
- $\dfrac{q_2}{q_1}<1$：明年苹果更便宜 → 通缩

2. 零息债券（承诺时期2支付1货币单位）
债券现价 $p_\gamma$
$$\frac{1}{p_\gamma}=1+i$$
$i$ = **名义利率**
> $p_\gamma$：今天付出的钱，期末拿到1单位货币

> 区分：名义利率由货币债券定义；后续会引出实物/实际利率

## 六、金融均衡定义
给定偏好、禀赋、股票股息，价格 $q_1,q_2,p_\alpha,p_\beta$、消费 $(X_{A1},X_{A2},X_{B1},X_{B2})$、持股 $\theta_{i\alpha},\theta_{i\beta}$ 满足两条：
1. A、B各自在两期预算约束下最大化自身效用；
2. 商品市场、股票市场全部出清。

## 七、对比：普通静态一般均衡 VS Fisher金融一般均衡
- 普通GE：同一时间，不同实物商品（苹果、橙子）
- 金融GE（Fisher）：同一种实物，**不同时间**；股票/债券作为跨期转移收入的工具；资产价值由未来股息决定

## 八、求解顺序（课上思路）
1. 套利条件锁定资产价格比例 $p_\alpha=\tfrac12 p_\beta$，减少未知数
2. 合并两期预算，得到**单期现值预算（等效禀赋）**，消去股票变量
3. 对A、B分别构造拉格朗日，求最优跨期消费 $X_1,X_2$
4. 代入市场出清，解价格比值 $q_2/q_1$，回代求股价、利率
5. 反推每个人最优持股数量 $\theta$
# Econ251｜Lecture 5 笔记（Geanakoplos）
> 来源：Chapter5 Present Value Prices + Chapter6 Real and Nominal Interest Rates
> 适配Obsidian，直接复制；承接上一篇Lecture4笔记
> 核心：Fisher现值价格（Present Value Prices）、等效禀赋化简、实际利率vs名义利率

## 一、核心思想：看穿金融资产的面纱（No-Arbitrage）
所有金融资产（股票α、股票β、债券）本质上都只是**跨期交换苹果的工具**：放弃今天的苹果，换取明年的苹果。
无套利约束：任何资产提供的「今天苹果 ↔ 明年苹果」交换比例必须完全一样，否则存在套利。
- 例：如果α价格不是β的1/2，所有人会做空α、买入β，拿到无风险利润，市场无法出清。
> 套利强制所有资产对应同一个跨期相对价格，也就是**现值价格**。

## 二、现值价格 Present Value Prices
- $P_1$：**现值价格**，今天支付、换取【今天的苹果】的价格
- $P_2$：**现值价格**，今天支付、换取【明年的苹果】的价格
> 重点：$P_1,P_2$ 都是**今天就要付的价格**，区别于同期现价 $q_1,q_2$
> $q_1$：时期1同期现价；$q_2$：时期2同期现价（明年才付钱）

资产定价和现值价格的换算：
$$P_2 = \frac{p_\alpha}{D_{\alpha2}} = \frac{p_\beta}{D_{\beta2}}$$
代入课上股息 $D_{\alpha2}=1,\ D_{\beta2}=2$：
$$P_2 = p_\alpha = \frac{p_\beta}{2}$$

## 三、等效禀赋 $\hat E$（Fisher化简魔法，本节课最重要）
把股票未来的股息收益，直接折算成代理人的未来禀赋，**把带股票的金融均衡，化简成普通两商品一般均衡**。
> 效用函数不变，只修改禀赋；求解这个简化GE，等价于求解原金融均衡。

课上给定折算结果：
- Agent A：$\hat E_A=(\hat E_{A1},\hat E_{A2})=(1,\ 3)$
  - 今天禀赋：1苹果
  - 未来禀赋：自带1苹果 + α股票股息1 + 一半β股息1 = 3
- Agent B：$\hat E_B=(\hat E_{B1},\hat E_{B2})=(1,\ 1)$
  - 今天禀赋：1苹果
  - 未来禀赋：自带1苹果 + 一半β股息1 = 1

效用（沿用之前）
$$U_A=\ln X_{A1}+\frac12\ln X_{A2}$$
$$U_B=\ln X_{B1}+\ln X_{B2}$$
> Cobb-Douglas性质：A花 $\boldsymbol{\dfrac23}$ 收入在$X_1$、$\boldsymbol{\dfrac13}$ 在$X_2$；B花 $\boldsymbol{\dfrac12}$ 收入在$X_1$、$\boldsymbol{\dfrac12}$ 在$X_2$

## 四、求解简化GE（标准化 $P_1=1$）
收入定义：
$$I_A = P_1 \hat E_{A1} + P_2 \hat E_{A2}=1+3P_2$$
$$I_B = P_1 \hat E_{B1} + P_2 \hat E_{B2}=1+P_2$$

时期1商品需求：
$$X_{A1}=\frac{2}{3}\frac{I_A}{P_1}=\frac{2}{3}(1+3P_2)$$
$$X_{B1}=\frac{1}{2}\frac{I_B}{P_1}=\frac{1}{2}(1+P_2)$$

时期1市场出清：$X_{A1}+X_{B1}=\hat E_{A1}+\hat E_{B1}=2$
$$\frac{2}{3}(1+3P_2)+\frac12(1+P_2)=2$$
解得：
$$\boldsymbol{P_2=\frac13},\quad P_1=1$$

消费解（课上结果）
$$X_{A1}=\frac43,\quad X_{B1}=\frac23$$

## 五、实际利率 Real Interest Rate $r$（Fisher核心变量）
定义：
$$1+r=\frac{P_1}{P_2}$$
代入 $P_1=1,\ P_2=\dfrac13$
$$1+r=\frac{1}{1/3}=3 \implies \boldsymbol{r=200\%}$$
含义：放弃1个今天的苹果，可以换到3个明年的苹果；**苹果的回报率（实物回报率）**。

资产定价（资产定价基本定理，实物版本）
$$p_\alpha = D_{\alpha2}\cdot P_2 = \frac{D_{\alpha2}}{1+r}$$
$$p_\beta = D_{\beta2}\cdot P_2 = \frac{D_{\beta2}}{1+r}$$
代入数字：
$$p_\alpha=\frac13,\quad p_\beta=\frac23$$

## 六、实际利率 vs 名义利率 vs 通胀
1. **现值价格 $P_1,P_2$ → 决定实际利率 $r$**（实物、跨期相对比价，这套模型可以解出来）
2. **同期现价 $q_1,q_2$ → 和通胀、名义利率有关**
    - 通胀因子：$\dfrac{q_2}{q_1}$
    - 名义利率 $i$：用货币债券定义
> 重要结论：这个模型**无法确定 $q_1,q_2$、通胀、名义利率 $i$**
> 原因：$q_1,q_2$ 同比例缩放不改变均衡，属于货币中性；想要解释通胀需要额外货币理论。

## 七、模型的局限（Geanakoplos重点强调）
1. 不能预测每个人持有哪只股票（$\theta_{i\alpha},\theta_{i\beta}$）
   α、β是线性同质资产，只要股息现金流成比例，持有组合不影响最终消费，持股分配不确定。
2. 不能解释通胀、不能解名义利率 $i$
3. 唯一稳定、有经济学意义的产出：**实际利率 $r$**，由偏好、禀赋分布决定。

## 八、Fisher一句话总结
无不确定性、完美预见的金融均衡 ≡ 普通一般均衡；
股票债券只是面纱，本质是**今天消费和未来消费的交换**；
真正重要的是**实物跨期相对价格（实际利率）**，不存在所谓“公正的利率”，它由偏好和禀赋内生决定。

## 九、符号对照表（方便串联L4+L5）
- $P_1,P_2$：现值价格（今天付钱，分别买今天/明年苹果）
- $q_1,q_2$：同期现价（在对应时期付钱买当期苹果）
- $1+r=\dfrac{P_1}{P_2}$：实际利率（苹果利率）
- $p_\alpha,p_\beta$：股票当期价格
- $D_{\alpha2},D_{\beta2}$：时期2股息
- $\hat E$：等效禀赋（股息折算后）
